# Заметки по развёртыванию

Это обезличенный порядок развёртывания для публичного портфолио-кейса.

1. Скопировать файлы проекта в корень сайта, например `/var/www/example`.
2. Создать базу данных MySQL и пользователя для Joomla.
3. Скопировать `configuration.example.php` в `configuration.php`.
4. Заполнить локальные значения: имя базы, пользователя, пароль, название сайта, пути и секрет.
5. Настроить nginx или Apache на папку проекта.
6. Выдать права на записываемые директории пользователю веб-сервера.
7. При необходимости импортировать локальный дамп базы для разработки.
8. Проверить маршрутизацию, загрузку файлов, кэш и доступ в админку в целевом окружении.

Боевые доступы, SQL-бэкапы и загруженные файлы организации нельзя коммитить в репозиторий.
